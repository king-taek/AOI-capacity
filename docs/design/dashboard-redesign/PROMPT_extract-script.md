---

이 프로젝트에서 `aoi-data.json`(화면이 읽는 데이터, 31일 × 30대, 2026-09-19 16:16 수집 기준)을 만들 때 쓴
**추출 스크립트와 조사 스크립트를 파일 그대로** 넘겨 주세요. Claude Code 쪽 저장소(`king-taek/AOI-capacity`,
`docs/design/dashboard-redesign/`)에 handoff 는 들어갔는데, 이 스크립트들만 빠져 있어 새 수집 결과로 화면을 갱신할 수 없습니다.

필요한 것 (있는 것 전부, 이름은 실제 파일명으로):

1. **`AOI_capacity 3.html` → `aoi-data.json` 변환 스크립트** (본체). 지금 폴더에 있는 `aoi-data.json` 을 만든 **바로 그 버전**이어야
   같은 입력으로 같은 출력이 나오는지 확인할 수 있습니다. 여러 번 고쳤다면 마지막 것과, 중간 것도 같이.
2. 그 스크립트가 import 하거나 읽는 **부속 파일** 전부 — `JOB_ALIAS`/Job 병합 표, Lot 이름 정리 규칙 표, 사용자 override 목록, 설정 JSON 등.
3. **조사 스크립트 4개** — `# check_aoi4_paths.py`(AOI-4 경로 확인), Scanresult 백업 폴더 조사, 백업 복구율 검수, 못 찾은 것 분류.
   결과 txt 는 이미 있으니 스크립트만.
4. `aoi-data.js` 와 오프라인 단일 HTML 을 만든 **번들 절차**(명령·스크립트)가 따로 있으면 그것도.
5. 실행 방법 한 줄씩 — 예: `python make_aoi_data.py "AOI_capacity 3.html" -o aoi-data.json`, 파이썬 버전, 표준 라이브러리 외 의존성.

주의:
- 코드를 **다시 쓰거나 정리하지 말고**, 실제로 돌린 파일을 그대로 주세요. 정리본은 규칙이 바뀌었는지 알 수 없습니다.
- 스크립트 안에 하드코딩된 경로(`X:\AOI-4`, `c:\Users\...`)는 그대로 두어도 됩니다. 제가 인자로 바꿉니다.
- `RULES.md` 에 적힌 규칙과 코드가 다른 곳을 알고 있으면 한 줄씩 적어 주세요(예: "Lot 꼬리표 표는 코드가 최신").
- 파일은 zip 하나로, 맨 위에 `README.md`(파일 목록 · 각 파일이 무엇을 만드는지 · 실행 순서)를 넣어 주세요.

이 스크립트들은 제품 `template.html` 로 이식할 때 규칙의 **원본 정의**로 쓰입니다(사용자 확정: 추정·Lot 단위 Error·재스캔 정의·
Job 병합·Lot 이름·라이트 테마·용어는 디자인 규칙 채택, Error 후 대기 상한과 하루 분모는 제품 규칙 유지).
