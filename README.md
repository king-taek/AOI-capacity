# AOI 장비 가동률

`aoi_collector_demo.html` 하나로 동작합니다. Python 없이 Edge 또는 Chrome에서 파일을 열어 사용합니다.

## 메뉴
- **홈**: 선택한 날짜의 모든 장비 가동률. 상단 요약(평균, 주의 장비, 오류 장비, 최저 장비), 정렬(낮은 순·오류 먼저·이름순), 카드/표 전환, 전일 대비 화살표. 카드를 클릭하면 24시간 타임라인(검사·오류·정지·미가동)과 오류 목록이 펼쳐집니다.
- **추이**: 일·주·월 단위 가동률 막대(전체 평균 또는 장비 하나)와 이번 기간 vs 이전 기간 비교 카드. 막대를 클릭하면 그 기간이 비교 기준이 됩니다.
- **장비 비교**: 선택한 날·최근 7일·최근 30일 기준 장비 순위. 이전 기간 막대와 변화폭을 함께 표시합니다.
- **설정**: NAS 공유 등록, 수집 실행, 이상 판정 기준, HTML 저장, 로그.

## 가동률 정의
- 가동률 = 검사시간(WaferStartTime~WaferEndTime 합) ÷ 24시간. 오늘이면 00:00부터 현재 시각까지로 나눕니다.
- 오류 Wafer 종료부터 다음 Wafer 시작까지의 공백을 "정지(추정)"로 봅니다. 장비 이벤트 로그가 아닙니다.
- 주·월 가동률 = 기간 내 검사시간 합 ÷ 기간 내 경과시간 합. 주는 월요일 시작입니다.

## NAS 등록
Camtek NAS 공유 하나(예: `Camtek 1~7`, X:)에 장비 여러 대의 폴더가 있습니다. 설정에서 공유마다 **폴더 선택**을 한 번 누르면 Report 폴더가 있는 하위 폴더를 자동으로 찾아 장비로 등록합니다. 수집할 때마다 다시 훑으므로 4층처럼 장비가 늘어나도 자동으로 추가됩니다. 같은 폴더명이 여러 NAS에 있으면 `4층 AOI-1`처럼 NAS 이름을 앞에 붙입니다.

## 제약
- 폴더 접근은 Edge/Chrome에서만 동작합니다. 다른 브라우저는 데모 보기만 가능합니다.
- 브라우저 보안상 매번 사람이 수집 버튼을 눌러야 합니다. 무인 정기 실행이 필요하면 Python 스크립트 방식이 맞습니다.
- 데모 데이터는 실제 검사 패턴을 바탕으로 장비 30대, 최근 5주 분량을 합성한 예시입니다.
