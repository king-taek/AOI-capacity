# AOI 장비 가동률

`aoi_collector_demo.html` 하나로 동작합니다. Python 없이 Edge 또는 Chrome에서 파일을 열어 사용합니다.

## 첫 화면
- **날짜 선택**: 상단에서 날짜를 고릅니다(← → 키, 날짜 입력, "최근" 버튼). 기본은 가장 최근 데이터 날짜입니다.
- **장비별 가동률 카드**: 장비마다 그 날 가동률 숫자 하나. 아래에 검사 / 오류 수 / 오류·정지 시간 / Wafer 수.
  - 가동률 = 검사시간 ÷ 24시간. 오늘이면 00:00부터 현재 시각까지로 나눕니다.
- **카드 클릭**: 그 장비의 그 날 24시간 타임라인(검사 파랑, 오류·정지 빨강, 미가동 회색)과 오류 목록이 펼쳐집니다.
- **일별 가동률**: 최근 7 / 14 / 30일 장비별 막대. 막대를 클릭하면 그 날짜·장비로 이동합니다.

## 설정 (오른쪽 위 톱니바퀴)
- 장비 목록: 장비명, 경로 메모, Report / Scanresult 폴더명, 폴더 선택.
- 장비마다 루트 폴더를 한 번 선택하면 브라우저가 기억합니다. 네트워크 드라이브(`M:\AOI-9`)와 UNC 경로(`\\10.20.30.11\AOI-10`) 모두 가능합니다.
- **수집 실행**: 장비별 최신 N개 Report를 읽고 Wafer마다 정확 경로의 `WaferInfo.ini`만 확인합니다(재귀 검색 없음, 원본 수정 없음).
- **HTML로 저장**: 수집 결과를 담은 파일로 저장하면 나중에 그 파일만 열어도 같은 화면이 보입니다.

## 제약
- 폴더 접근은 Edge/Chrome에서만 동작합니다. 다른 브라우저는 데모 보기만 가능합니다.
- 브라우저 보안상 매번 사람이 버튼을 눌러야 합니다. 무인 정기 실행이 필요하면 Python 스크립트 방식이 맞습니다.
- 정지 시간은 오류 Wafer 종료부터 다음 Wafer 시작까지의 공백으로 추정한 값이며 장비 이벤트 로그가 아닙니다.
