# AOI 장비 가동률 수집기

`aoi_collector_demo.html` 하나로 동작하는 브라우저 기반 수집기입니다. Python 없이 Edge 또는 Chrome에서 파일을 열어 사용합니다.

## 화면 구성
- **개요**: 평균 추정 가동률, 장비 카드, 공용 시간축 스윔레인, 가동 상태 구성, Wafer 결과 상태
- **가동 상태·공백**: 연속 Wafer 사이 공백을 IDLE / SETUP / USER_STOP / DOWN 후보 / UNKNOWN으로 분류. 임계값 조정 가능
- **Lot · Batch**: BatchReport 1개당 1행, Carrier 25슬롯 스트립
- **상세 데이터**: 원천 행 검색·필터·정렬, 행 클릭 시 전체 필드 드로어
- **데이터 품질**: INI 연결률, NOT_FOUND, 불일치, 시간 역전, 재검사 등 지표
- **장비·경로 설정**: 장비 목록, 폴더 선택, 수집 실행, 로그

## 사용 방법
1. `aoi_collector_demo.html`을 Edge/Chrome에서 엽니다. 처음에는 데모 데이터(장비 3대로 재구성한 샘플 459행)가 표시됩니다.
2. 1번 표에서 장비마다 **폴더 선택**을 눌러 장비 루트 폴더(`Report`, `Scanresult`가 들어 있는 폴더)를 고릅니다. 네트워크 드라이브(`M:\AOI-9`)나 UNC 경로(`\\10.20.30.11\AOI-10`) 모두 가능합니다.
3. **실제 수집 실행**을 누르면 장비별로 최신 N개 Report를 읽고, 각 Wafer의 `WaferInfo.ini`를 정확 경로로만 확인합니다(재귀 검색 없음).
4. **CSV 저장** 또는 **이 화면 그대로 HTML 저장**으로 결과를 남깁니다. 저장된 HTML은 다시 열면 결과가 그대로 보입니다.

## 제약
- 폴더 접근 API(File System Access API)는 Edge/Chrome에서만 동작합니다. 다른 브라우저는 데모 보기와 저장만 가능합니다.
- 브라우저 보안상 매번 사람이 버튼을 눌러야 합니다. 무인 정기 실행이 필요하면 Python 스크립트 방식이 맞습니다.
- 선택한 폴더 핸들은 브라우저(IndexedDB)에 저장되어 다음 실행 때 권한 확인만 다시 묻습니다.
