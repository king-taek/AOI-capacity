AOI 장비 가동률 수집기 데모 데이터

여러 대의 AOI 장비 BatchReport와 WaferInfo.ini를 브라우저에서 직접 읽어 원천 데이터를 만들고, 장비별 추정 가동률을 계산합니다. 원본 파일은 읽기만 하며 수정하지 않습니다.

1. 장비 목록과 네트워크 경로

장비마다 루트 폴더를 한 번 선택합니다. 루트 아래에 Report, Scanresult 폴더가 있어야 합니다. 네트워크 드라이브(M:)나 UNC 공유 폴더 모두 폴더 선택창에서 고를 수 있습니다.

장비명경로 메모ReportScanresult폴더
이 브라우저는 폴더 접근 API를 지원하지 않습니다. Edge 또는 Chrome에서 이 파일을 열어 주세요. 데모 데이터 보기와 CSV 저장은 가능합니다.

2. 결과 저장

저장 파일명: AOI_raw_data_YYYY-MM-DD_HHMMSS. Edge/Chrome에서는 저장 위치를 직접 고르고, 다른 브라우저에서는 다운로드 폴더로 내려갑니다.

4. 장비별 집계와 추정 가동률

가동률은 INI의 WaferStartTime~WaferEndTime 합계를 관측 구간(해당 장비의 첫 Wafer 시작 ~ 마지막 Wafer 종료)으로 나눈 추정치입니다. 장비 이벤트 로그가 아니므로 Error 이후 공백을 실제 다운타임으로 단정하지 않습니다.
